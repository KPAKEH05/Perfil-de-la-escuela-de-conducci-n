# Автошкола «Профиль» — сайт-визитка

Адаптивный сайт на HTML/CSS/JavaScript + Node.js/Express.

## Возможности
- презентация автошколы, преимуществ, форматов обучения и стоимости;
- FAQ, контакты и мобильная навигация;
- форма обратной связи с клиентской и серверной валидацией;
- заявки сохраняются в `data/leads.json`;
- honeypot-поле и ограничение частоты отправки;
- логотип и фотографии из предоставленного архива.

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm start
```
Откройте http://localhost:3000

## Заявки
После первой заявки создаётся `data/leads.json`. Это демонстрационное хранилище, не CRM. Не публикуйте файл и ограничьте доступ к серверу.

## API
- `GET /api/health` — проверка сервера.
- `POST /api/leads` — JSON: `name`, `phone`, `message` (опционально), `consent` (true), `website` (honeypot, пустое).

## Перед публикацией
1. Подтвердите актуальность цены, расписания и формулировок об экзаменах.
2. Заполните и согласуйте `public/privacy.html`.
3. Настройте HTTPS, резервное копирование и права доступа к `data/`.
4. Для реальной эксплуатации замените JSON на защищённую БД/CRM, добавьте админ-аутентификацию.
5. Настройте уведомления о заявках и дополнительную защиту от спама.

Контент подготовлен по файлу «Автошкола Профиль — инфо со старого сайта.docx».
